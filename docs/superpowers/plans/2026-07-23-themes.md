# Theme System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a 7-family × light/dark theme system to the dashboard, switchable from the sidebar and persisted in localStorage, with no flash on load.

**Architecture:** Two attributes on `<html>` (`data-theme`, `data-mode`) select a palette. `globals.css` keeps the current `@theme` block as the SocialScheduler-light default and adds one CSS override block per (family, mode) that redefines the existing `--color-*` tokens. A blocking `<head>`-level script applies the persisted attributes before paint; a client control writes them + localStorage. No schema/route/worker change, no new dependency.

**Tech Stack:** Next.js 16 (App Router) + TypeScript + Tailwind v4 (CSS-first `@theme`).

## Global Constraints

- **No new dependency** (no `next-themes`), no schema/migration/route/worker change, nothing written to `/data`. Presentation layer only.
- **Default theme is visually unchanged:** SocialScheduler-light stays exactly as today. It is the `@theme` default and needs **no** override block; only the other 13 palettes get blocks.
- **20-token contract** per palette; the 13 blocks each set the **15 non-status tokens**. Status tokens are shared: light status = the `@theme` default (unchanged); one extra `html[data-mode="dark"]` block supplies the brightened dark status set. Family blocks never set status tokens (v1).
- **No unit-test harness in `dashboard/`** — verification is `npx tsc --noEmit` + browser (matches the project's existing route-verification pattern).
- All values are copied **verbatim** from `docs/design-themes.md` §4–§5. Do not re-derive or "improve" colors.
- Route handlers/pages that are server components stay server components; only `theme-controls.tsx` is a new client component (the sidebar is already `"use client"`).

```ts
// dashboard/lib/themes.ts
export type ThemeId =
  | "socialscheduler"
  | "claude"
  | "apt"
  | "fyzical"
  | "default"
  | "solarized"
  | "vela";

export type ThemeMode = "light" | "dark";

export const THEMES: { id: ThemeId; label: string }[] = [
  { id: "socialscheduler", label: "SocialScheduler" },
  { id: "claude", label: "Claude" },
  { id: "apt", label: "APT" },
  { id: "fyzical", label: "FYZICAL" },
  { id: "default", label: "Default" },
  { id: "solarized", label: "Solarized" },
  { id: "vela", label: "Vela" },
];

export const DEFAULT_THEME: ThemeId = "socialscheduler";
export const DEFAULT_MODE: ThemeMode = "light";

export const THEME_STORAGE_KEY = "ss-theme";
export const MODE_STORAGE_KEY = "ss-mode";

const THEME_IDS = new Set<string>(THEMES.map((t) => t.id));

export function isThemeId(v: string | null): v is ThemeId {
  return v !== null && THEME_IDS.has(v);
}

export function isMode(v: string | null): v is ThemeMode {
  return v === "light" || v === "dark";
}
```

- [ ] **Step 1: Create `theme-controls.tsx`**

```tsx
"use client";

import { useEffect, useState } from "react";
import {
  THEMES,
  DEFAULT_THEME,
  DEFAULT_MODE,
  THEME_STORAGE_KEY,
  MODE_STORAGE_KEY,
  isThemeId,
  isMode,
  type ThemeId,
  type ThemeMode,
} from "@/lib/themes";

function MoonIcon() {
  return (
    <svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden>
      <path d="M21 12.79A9 9 0 1 1 11.21 3 7 7 0 0 0 21 12.79z" />
    </svg>
  );
}

function SunIcon() {
  return (
    <svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round" aria-hidden>
      <circle cx="12" cy="12" r="4" />
      <path d="M12 2v2M12 20v2M4.93 4.93l1.41 1.41M17.66 17.66l1.41 1.41M2 12h2M20 12h2M6.34 17.66l-1.41 1.41M19.07 4.93l-1.41 1.41" />
    </svg>
  );
}

export function ThemeControls() {
  const [theme, setTheme] = useState<ThemeId>(DEFAULT_THEME);
  const [mode, setMode] = useState<ThemeMode>(DEFAULT_MODE);

  // Sync the control to whatever the no-flash script already put on <html>.
  useEffect(() => {
    const d = document.documentElement;
    const t = d.getAttribute("data-theme");
    const m = d.getAttribute("data-mode");
    if (isThemeId(t)) setTheme(t);
    if (isMode(m)) setMode(m);
  }, []);

  function applyTheme(next: ThemeId) {
    setTheme(next);
    document.documentElement.setAttribute("data-theme", next);
    try {
      localStorage.setItem(THEME_STORAGE_KEY, next);
    } catch {}
  }

  function applyMode(next: ThemeMode) {
    setMode(next);
    document.documentElement.setAttribute("data-mode", next);
    try {
      localStorage.setItem(MODE_STORAGE_KEY, next);
    } catch {}
  }

  const nextMode: ThemeMode = mode === "light" ? "dark" : "light";

  return (
    <div className="flex items-center gap-2 px-1">
      <label className="sr-only" htmlFor="theme-select">
        Theme
      </label>
      <select
        id="theme-select"
        value={theme}
        onChange={(e) => applyTheme(e.target.value as ThemeId)}
        className="min-w-0 flex-1 rounded-lg border border-border bg-surface px-2 py-1.5 text-[12px] text-ink focus:border-brand"
      >
        {THEMES.map((t) => (
          <option key={t.id} value={t.id}>
            {t.label}
          </option>
        ))}
      </select>
      <button
        type="button"
        onClick={() => applyMode(nextMode)}
        aria-label={`Switch to ${nextMode} mode`}
        title={`Switch to ${nextMode} mode`}
        className="shrink-0 rounded-lg border border-border bg-surface p-2 text-ink-soft transition-colors hover:bg-surface-sunken"
      >
        {mode === "light" ? <MoonIcon /> : <SunIcon />}
      </button>
    </div>
  );
}
```
